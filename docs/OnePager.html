Automation Framework Case Study: SauceDemo

Team: Abhinav (231070028), Amit (231070020), Chaitanya (231070066), Prasanna (231070024), Ritesh (231070053), Yogesh (231070037)

Scope

AUT: https://www.saucedemo.com, user standard_user. Nine functional requirements automated: the six mandatory ones (FR-01, 02, 07, 12, 14, 16) and three extra (FR-04, 09, 11; FR-04 is the extra negative case). Three performance requirements (NFR-01 to 03) tested with JMeter. Test cases derived with Equivalence Partitioning and Boundary Value Analysis.

Framework

Python 3.11+, Selenium 4.52, PyTest 9.2, pytest-html 4.2, webdriver-manager 4.1, Apache JMeter 5.6.3.

  • Page Object Model: locators and actions live in pages/; tests only call page methods.
  • Explicit waits only (WebDriverWait), no time.sleep; waits retry when the page re-renders an element.
  • Data-driven: login and postal code cases read from CSV files in testdata/.
  • Markers: smoke for happy paths, regression for the full suite.
  • Evidence: screenshot on failure (saved and embedded in the HTML report), step log per test, HTML report.
  • Traceability: every case has a TC ID mapped to its FR and test function in docs/traceability.csv.

Structure

pages/        page objects (7 pages + base page)
tests/        one test file per module
testdata/     CSV test data
utils/        config, CSV loader, step logger
docs/         test cases, defects, traceability
performance/  JMeter plan, results, dashboard
reports/      HTML report, screenshots, logs

How to run

pip install -r requirements.txt
pytest -m smoke     smoke suite
pytest              full suite + HTML report

jmeter -n                          (one command)
  -t performance/jmx/saucedemo_weekend_lab.jmx
  -l performance/results/results.jtl
  -e -o performance/html_report
